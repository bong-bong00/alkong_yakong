[알콩약콩 향후 고도화 및 작업 리스트]

현재 성공적으로 구축된 핵심 기능(OCR 처방전 인식, 알람 스케줄링, 식약처 데이터 기반 AI 약사 챗봇)을 바탕으로, 앞으로 앱의 완성도를 극대화하기 위해 진행해야 할 향후 작업 리스트입니다.

================================================================================
1. 데이터 및 API 연동 (백엔드)
================================================================================
[ ] 식약처 API 정식 연동 (E_DRUG_API_KEY 세팅)
  - .env 파일에 공공데이터포털에서 발급받은 실제 API 키를 삽입하여, 로컬 DB뿐만 아니라 실시간으로 최신 식약처 약품 데이터를 가져오도록 연결.
[ ] DUR (의약품안전사용서비스) 병용금기 알림 고도화
  - 현재 처방받은 약들 중에 같이 먹으면 안 되는 약(병용금기), 임산부 금기 약물 등이 있는지 식약처 DUR API를 찔러서 경고해주는 기능 완전 자동화.

================================================================================
2. AI 약사 챗봇 사용성 개선 (프론트엔드/백엔드)
================================================================================
[ ] 챗봇 응답 스트리밍(Streaming) 적용
  - 제미나이가 대답을 다 완성할 때까지 로딩 화면만 보는 대신, 챗GPT처럼 글자가 한 글자씩 실시간으로 타이핑되며 나타나도록 개선하여 체감 대기시간 단축.
[ ] 채팅 내역 로컬 DB 영구 저장
  - 앱을 껐다 켜도 예전에 AI 약사와 나눴던 대화 기록이 남아있도록 SQLite에 채팅 기록 저장.
[ ] 어르신 맞춤형 '빠른 질문(Quick Reply)' 버튼 추가
  - 채팅창 입력이 불편한 분들을 위해 "이 약 부작용은?", "식전에 먹어도 돼?", "까먹고 안 먹었는데 어떡해?" 등의 자주 묻는 질문 버튼을 UI에 배치.

================================================================================
3. 처방전 및 복약 관리 고도화 (프론트엔드)
================================================================================
[ ] 복약 달력(Calendar) UI 완벽 연동
  - 생성된 알람 스케줄(medication_schedules) 데이터를 달력 화면에 뿌려서, 한 달 동안 약을 잘 먹었는지 도장(O, X) 형태로 시각화.
[ ] 복약 알람(Push Notification) 실제 작동
  - 시간에 맞춰 핸드폰 자체 푸시 알람이 쩌렁쩌렁 울리고, "약 먹었음" 버튼을 누르면 DB 상태가 'COMPLETED'로 바뀌도록 네이티브 알람 연동.

================================================================================
4. 테스트 및 상용화 준비
================================================================================
[ ] 다양한 형태의 약 봉투/처방전 사진 테스트 (예외 처리 강화)
  - 글씨가 찌그러지거나 흐릿한 사진에서도 OCR_SCHEMA가 터지지 않고 부드럽게 에러 메시지를 뱉도록 안전장치 마련.
[ ] 사용자(User) 로그인 세션 분리
  - 현재 MVP용 하드코딩된 'test_user' 대신, 카카오톡 로그인이나 기기 고유 ID를 통한 실제 유저 분리 작업.
