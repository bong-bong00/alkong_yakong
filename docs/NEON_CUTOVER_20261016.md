- 기존 SQLite 백업과 원본 API 추출 자료는 Git 외부의 개인 백업 폴더에 유지했다.

## 첫 저장 오류 수정

새 PostgreSQL 연결의 초기 트랜잭션 종료 후 스키마 캐시가 남아,
첫 쿼리가 `BEGIN IMMEDIATE`인 쓰기 경로에서 스키마 설정이 누락됐다.
초기 커밋도 연결의 `commit()` 메서드를 사용해 캐시를 비우도록 수정했다.
회귀 테스트와 실제 Neon의 새 연결에서 명시적 트랜잭션을 검증했다.
또한 SQL 어댑터의 자동 저장점이 애플리케이션 저장점을 지우지 않도록
`SAVEPOINT`·`RELEASE`·`ROLLBACK TO`는 별도로 처리했다.

## 앱 적용

- 새 약 서버 주소가 포함된 APK로 업데이트하고 다시 로그인해야 한다.
- 앱 빌드에는 `--dart-define=NEON_DATABASE_ACTIVE=true`를 적용했다.
- DB 파일을 매일 내려받아 동기화하는 구조가 아니다. 전환된 서버의 저장은 Neon에 직접 반영된다.
- 무료 약 서버의 휴면 후 첫 요청은 지연될 수 있다.
- 실제 Polar 하드웨어 측정 및 의료적 답변 정확도는 API 연동 테스트만으로 보증하지 않는다.
- 비밀 연결 주소와 인증키는 Render 환경변수 및 Git 외부 파일로만 관리한다.
