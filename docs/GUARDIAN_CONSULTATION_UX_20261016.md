# 보호자 상담과 표시 UX 보완

## 반영 범위

- 보호자 하단 탐색에 `AI 약사`를 추가한다.
- 상담 상단에서 기본 `일반 약 상담` 또는 연결된 환자를 선택한다. 환자 상세에서 진입하면 해당 환자를 미리 선택한다.
- 일반 상담은 개인 건강정보, 등록 약, 최근 OCR을 자동으로 가져오지 않는다. 일반 상담에는 건강 맞춤 키워드를 표시하지 않으며, 기존 환자용 키워드 문구는 변경하지 않는다.
- 일반 상담 요청은 `consultation_mode=general`을 보낸다. 서버에서도 건강 맞춤 조회, 등록 약 전체 조회, 과거 개인 DUR 결과 재사용을 하지 않는다. 병용 검사는 검색·선택한 약에만 한정한다.
- 일반/환자별 화면은 다른 키로 다시 생성하고, 대화·답변 캐시는 보호자 계정과 대상별로 구분한다. 기존 연결 동의 확인과 해제 후 차단을 유지한다.
- 환자 이름을 기본 표시로 쓰고 관계 값은 별도 데이터로 유지한다.
- 대리 등록 배너는 환자 이름과 기능을 두 줄로 구분하고, 버튼은 `○○ 님 약 등록하기`로 표시한다. 약·복용 일정 등록 결과도 안내한다.
- 보호자 연결 수락 전에 약·복약·심박·건강정보 조회, 처방전 대리 등록, AI 대리 상담 범위를 안내한다.
- 최근 심박수에 bpm과 측정 시각을 표시한다. 과거 값도 최신값일 수 있으므로 오늘 측정으로 표현하지 않는다. 시각이 없으면 미확인으로 표시한다.
- 보호자 현황에서 복약 정보 로딩/조회 실패/등록 약 없음/오늘 일정 없음을 구분한다.
- 기간 내 복약 전후 기록이 없으면 큰 빈 그래프를 생략한다. 기록이 있으면 가로 스크롤 안내를 제공한다.

## 검증 및 적용

### 후속 화면 보완

- 환자 상담의 약 선택/변경 버튼을 제거했다. `consultation_mode=patient_all` 요청은 서버가 매번 현재 등록 약 전체를 읽으며 과거 선택·임시 검색 약으로 범위를 대체하지 않는다. 빈 목록/조회 실패는 별도 안내하고 모델을 호출하지 않는다.
- 일반 상담의 중복 보조 문구를 제거하고 첫 인사를 짧게 정리했다.
- 긴 건강정보는 항목명 아래 전체 너비로 표시하고, 전화번호는 한 줄로 맞춘다. 조회 실패를 미입력으로 표시하지 않는다.
- 관리 목록에는 나이와 관계를 함께 표시한다. 환자 카드의 이름·배지·복약·최근 심박 정보를 분리하고 중복된 ‘약’ 문구를 수정했다.
- 미확인 알림만 기본 표시하며 확인한 알림은 별도 목록에서 조회한다. 종 배지는 확인 필요 환자 수가 아닌 같은 기준의 미확인 알림 건수다. 연결 환자가 여럿이면 모두의 알림을 함께 조회한다. 확인은 복약 완료를 생성하거나 서버 알림을 삭제하지 않는다.
- 알림 확인 표시는 현재 기기의 SharedPreferences에 보호자/환자별로 저장된다. 다른 기기와 서버 동기화하는 기능은 아니다.
- 정보 → 설정 → 계정 관리로 로그아웃/탈퇴를 이동했다. 공통 계정 관리 화면의 실제 서버 삭제/실패 처리 흐름을 재사용하고, 보호자 탈퇴가 환자 계정 삭제를 의미하지 않음을 안내한다. 하위 화면의 뒤로가기와 상담 로딩 화면의 뒤로가기를 유지한다.
- 백엔드 807개 통과·3개 건너뜀, Flutter 852개 통과 및 정적 분석을 검증했다. 실제 운영 계정의 로그아웃/탈퇴는 시험하지 않았다.

일반/환자 대상 전환과 기록 분리, 일반 상담의 개인 데이터 미조회, 작은 화면 360×640의 기본/2배 글씨, 기존 연결 해제 접근 차단을 회귀 시험에 포함한다.

이 작업은 로컬 수정이다. 새 일반 상담 모드의 서버 처리는 메인 서버를 배포해야 적용되며, 화면 변경은 앱을 다시 빌드해야 적용된다. 기존 운영 배포와 이번 수정 완료 상태를 구분한다. 사용자 요청 없이 커밋·푸시·배포하거나 기존 별도 변경을 포함하지 않는다.
