# AI 약사 보완 및 보호자 대리 상담 (2026-10-16)

## 범위와 상태

`AI_PHARMACIST_QA_20261016.md`의 최초 점검 이후 보완 작업이다. 이 문서의 수정은 로컬 작업이며, 커밋·푸시·운영 배포 완료를 의미하지 않는다. 운영 서버에서 수정본 전체 시나리오를 다시 시험해야 한다.

사용자 요청에 따라 일반·등록 약 전체·선택 약·건강 질문의 기존 키워드 문구와 전송 질문은 변경하지 않았다. 보호자 환자 상세 화면에는 해당 환자 명의 상담 진입 버튼과 상담 대상 표시만 추가하였다.

## 반영 사항

- 복수 약의 정식 이름에 성분·수출명이 붙어 있어도 모호하지 않은 표시 이름으로 답변 포함 여부를 확인한다. 다른 함량이나 동명 제품을 같은 약으로 취급하지 않는다.
- 생성 실패 시 확인된 공식 자료의 완결된 일부 문장을 제공하고, 일부 안내이며 안전 판정이 아님을 표시한다.
- 음식·음료 질문은 약끼리의 병용 검사와 구분한다. 음식과 복수 약 병용을 함께 묻는 질문은 병용 검사를 유지한다.
- 동일 성분, 공식 효능의 유사성, 식약처 효능군 중복 등재 여부를 구분한다. 미등재를 효능이 전혀 다르거나 함께 복용해도 안전하다는 뜻으로 안내하지 않는다.
- DUR 백그라운드 동기화를 끈 경우에도 사용자가 요청한 상담 검사는 수행한다. 상담에 필요한 검사 종류만 요청하며 요청하지 않은 종류는 미확인으로 남긴다. 식약처의 빈 객체 응답을 가짜 결과 한 건으로 취급하지 않는다.
- 건강 주의사항은 약별 관련 질환·음주 등의 반영 여부를 확인한다. 조건을 안전하게 축약할 수 없거나 추가 설명이 필요한 항목은 확인 필요 대상으로 명시한다.
- 자유 형식 용법 질문에도 공식 설명서의 일반 용법이라는 안내를 적용한다. 임의 증량 요청은 거절하고, 포괄적인 증상만으로 복용 중단을 지시하는 답변은 재생성/공식 자료 대체 대상으로 처리한다.
- 짧게 요약 요청은 짧은 원문에도 적용하되 수치·조건 보존 검증에 실패하면 원문을 유지한다. 따라서 모든 응답의 고정 글자 수를 보장하지 않는다.
- 답변 정책 버전을 올려 기존 자동 답변 캐시를 재사용하지 않도록 했다. 기존 대화 기록 자체는 삭제하지 않는다.

## 보호자 대리 상담과 접근 제어

- 연결 및 동의가 유효한 환자에 한하여 메인 서버 상담/상담 캐시 검증 요청을 허용한다. 다른 환자와 연결 해제 후 요청은 거부한다.
- 환자의 약·건강정보를 조회하고, 로그인 주체는 보호자로 유지한다.
- 보호자 본인 및 각 환자의 로컬 대화/답변 캐시를 별도 구분한다. 보호자의 최근 OCR 자료를 환자 약으로 대체하지 않는다.
- 전송·이전 대화 열기 전에 온라인 권한을 재확인한다. 검증 실패 시 저장 답변으로 우회하지 않고 화면의 환자 자료를 지운다.
- 화면이 열린 후 계정이 바뀌면 전송을 차단한다.

## 검증과 한계

Flutter 전체 844개 테스트가 통과했고, `flutter analyze`는 지적 사항이 없다. 보호자 본인/환자별 대화 분리, 연결 해제, 보호자 OCR 혼입 방지, 계정 변경 및 권한 확인 도중 계정 변경 차단을 포함한다.

백엔드 전체 시험은 800개 통과, 3개 건너뜀, 추가 하위 시험 111개 통과를 확인했다. 기존 FastAPI 시험 도구의 폐기 예정 경고 1개가 있으며 실패는 없다. 실제 제공자 시험은 가상 사용자/로컬 SQLite를 사용하며 운영 환자 DB에 시험 자료를 추가하지 않는다. 약 서버 연결 부분은 로컬 어댑터로 검사하므로 운영 두 서버 간 통합 시험과 구분해야 한다.

실제 식약처·Gemini 재시험에서 대표 세 약의 선택 대상 유지, 복수 효능 안내, 유사 효능과 동일 성분의 구분, 음식 안내가 확인되었다. 단일 주의사항 답변은 조건 보존을 위해 긴 원문을 유지한 사례도 있었다. 생성형 답변의 모든 반복 결과, 전체 의약품 조합 또는 의학적 정확도를 보증하지 않는다.

실제 생성 답변의 포괄적인 중단 지시가 검출되어 재생성 및 공식 자료 대체가 실행되는 것도 확인했다. 대체 인용에서 절 제목만 보여 주지 않도록 추가 회귀 시험을 반영했다. 정상 검사 0건 안내에도 모든 상호작용과 개인별 안전성을 보장하지 않는다는 제한을 추가했다.
