## 0. 고정 규칙 (모든 화면 공통)
- 화면 크기 기준: 390 × 844 (iPhone 14). 위치 (x, y)는 화면 왼쪽 위 기준 px.
- 화면 배경: **#F7F7FA** (거의 흰색). 헤더·하단 탭바는 #FFFFFF.
- 카드·보조 버튼: **#FFFFFF** + 카드 그림자
  - CSS: `0 1px 2px rgba(17,17,20,0.05), 0 2px 8px rgba(17,17,20,0.04)`
  - Flutter: `BoxShadow(color: Color(0x0D111114), offset: Offset(0,1), blurRadius: 1)`, `BoxShadow(color: Color(0x0A111114), offset: Offset(0,2), blurRadius: 6)`
  - Flutter에서 `Card`/`Material elevation` 쓰지 말 것 (`elevation: 0`, `surfaceTintColor: Colors.transparent`). 그림자는 `BoxDecoration`으로만.
- 흰 카드 안의 보조 면: #F0F1F5 (그림자 없음). 회색 위에 회색 금지.
- 주 액션: 파랑 채움 + 흰 글씨 900, 높이 70px 이상, 모서리 18px. 파랑은 주 액션·선택된 항목에만.
- 위험 액션: #C0392B 채움 흰 글씨 — 화면당 최대 1개.
- 글씨: 본문 18px 이상, 제목 24px 이상, 가장 연한 회색 #8A8A93. 글꼴 Noto Sans KR (500/700/900), 아이콘 Material Symbols Rounded.
- 버튼 모양: 둥근 사각(알약 모양 금지). 큰 버튼 18px, 작은 버튼 14px. 테두리 없음.
- 음성 복약 기록 없음 · 심박수는 복약 전/후 2번 · 보호자 전화 걸기 버튼 없음.

## 읽는 법
- `[박스]` 배경·그림자·테두리가 있는 면, `[버튼]` 누를 수 있는 면. 들여쓰기 = 안에 들어 있음.
- `W×H @x,y` 크기와 위치, `r` 모서리, `그림자:카드` = 위 카드 그림자.
- `"문구" 21/900 #111114` = 글자 21px, 굵기 900, 색.
- 상단 상태바(시간·배터리, 위 46px)는 생략.
- `(스크롤)` 표시는 첫 화면 아래로 스크롤해야 보이는 부분.
