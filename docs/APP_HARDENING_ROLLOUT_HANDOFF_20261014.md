### 운영자가 실행할 DB 검증/적용

애플리케이션 쓰기를 중지한 점검 시간에 실제 DB를 지정한다. 아래는 경로 예시일 뿐 현재 서버 경로가 아니다. 백업은 영구 저장소에 보관하고 암호화된 별도 저장소에도 확보한다.

```sh
python scripts/hardening_database.py --database /var/data/alkongyakong.db
python scripts/hardening_database.py --database /var/data/alkongyakong.db --apply --backup /var/data/backups/before-hardening-20261014.db
```
